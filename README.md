# KR8 ENTITIES

Five-page interior design website for KR8 ENTITIES in Midrand. It showcases bespoke wardrobes, kitchens, living spaces, bars and finishing details, with the studio's photos and information served from public storage. Booking requests continue in WhatsApp at 0601910837.
